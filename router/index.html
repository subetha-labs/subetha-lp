01 / Why

Use the rail you hold.

A supported payment rail can connect your agent to an API that accepts another, without acquiring the provider’s asset.

Agent → Router

Pay on the source rail.

The agent pays the Router using a supported asset and network. Listing routes and requesting a quote never initiate payment.

Router → Provider

Two independently funded payments.

The Router separately pays the provider from its own prefunded balance, then returns the API response. This is not a swap or bridge; it does not guarantee unlinkability or anonymity. The two payments are not atomic.

03 / Try without a wallet

List. Quote. Stop.

No repository clone, wallet, key or Router account is needed. The list and quote tools never initiate payment. Choose an MCP client, or use curl below to list routes without a paid agent client.

1 · Connect an MCP client

In Claude Code, register the hosted HTTP endpoint with this command.

claude mcp add --transport http subetha-router https://router.subethalabs.com/mcp

Any compatible MCP client

Add this HTTPS MCP endpoint in your client’s connection settings. Client availability and pricing are separate from Router access.

https://router.subethalabs.com/mcp

2 · Ask for one static quote, then stop

Paste this instruction into the connected agent. If the example route is no longer listed, it must stop without substituting another route.

Do not pay. Use only subetha_router_list_routes and subetha_router_quote. First call subetha_router_list_routes. If md-mpp-eth-snapshot is still listed, call subetha_router_quote exactly once with that routeId and a fresh UUID requestId. If it is absent, stop. Explain the source (agent to Router) and destination (Router to provider), including protocol, network, asset, amount, decimals, expiry and fundsMoveOnCredential. Then STOP at the quote. Do not sign, read keys, create a wallet, approve, or call purchase. Do not call any other tools.

Or: list routes from a terminal

This raw HTTP request uses curl only. It lists routes; it does not quote, sign or pay.

curl -sS --max-time 30 https://router.subethalabs.com/mcp \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -H 'MCP-Protocol-Version: 2025-03-26' \
  --data '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"subetha_router_list_routes","arguments":{}}}'

Check the JSON-RPC result.structuredContent: expect ok: true, routes and dynamic.profiles. SSE responses may put the JSON on data: lines. HTTP 200 alone is not success; check for JSON-RPC or tool errors. Use the returned listing for current counts.

05 / Before a paid trial

Local signing needs
explicit approval.

Public local signing setup is being prepared. Paid trials require an available local signer, funds on the matching testnet (including any network fees), and explicit human approval.

Approve before any potentially spending signing step. Tempo MPP credential creation sends funds before purchase. Solana MPP locally signs first; the Router broadcasts at purchase, and the caller needs devnet SOL for the fee. Read fundsMoveOnCredential and the rail-specific behavior; the flag is not evidence that payment completed.

approval=quoteId binds a purchase to a quote; it does not prove human consent. The client must obtain that consent. The server cannot verify that a human actually approved. A Router rejection does not mean no funds moved: a Tempo credential may already have sent them.

Do not automatically retry paid_data_unavailable, unknown or awaiting_payment. These outcomes are not proof of nonpayment. Reconcile the existing outcome first; a new purchase requires a fresh quote and renewed human approval before signing. No refund is guaranteed.

Advanced: compatible third-party providers

Dynamic profiles accept conditional provider URLs, not arbitrary APIs: public HTTPS, a supported protocol, network and asset, and matching price and challenge constraints. Redirects are not supported. The quote includes the provider price plus the Router fee. Providers are unverified; only a GET response containing an application/json object up to 256 KiB is supported. Payment can succeed without usable data, and there is no refund guarantee.

06 / FAQ

The short answers.

Can I complete a paid trial from these instructions?+

These instructions end at discovery and a static quote. Public local signing setup is still being prepared; connecting an MCP client alone does not provide a signer or testnet funds.

Does the Router hold my key?+

No caller private key is given to the Router. The caller signs locally and supplies a signed payment credential, which can authorize inbound settlement. The Router uses its own key and prefunded balance for the separate outbound payment.

Does this make my payments anonymous?+

No. Separate funding does not guarantee unlinkability or anonymity. This routing PoC makes no privacy or atomic-settlement guarantee.

Is this production software?+

No. It is an unaudited, testnet-only proof of concept. Historical settlement and data-delivery records do not guarantee current availability or future purchase results.

03 / ウォレットなしで試す

一覧。見積。そこで停止。

リポジトリの clone、ウォレット、鍵、Router のアカウントは不要です。一覧と見積のツールは支払いを開始しません。MCPクライアントを使うか、下の curl で有料エージェントクライアントなしに一覧を取得できます。

1 · MCPクライアントを接続

Claude Code では、このコマンドでホスト済みHTTPエンドポイントを登録します。

claude mcp add --transport http subetha-router https://router.subethalabs.com/mcp

他の対応MCPクライアントでも

クライアントの接続設定に、この HTTPS MCP エンドポイントを追加してください。クライアント自体の利用条件・料金は Router への接続とは別です。

https://router.subethalabs.com/mcp

2 · 固定ルートの見積を1回だけ取り、停止

接続したエージェントに次の指示を貼り付けてください。例のルートが一覧になければ、別ルートに置き換えずに停止します。

支払いはしないでください。使うツールは subetha_router_list_routes と subetha_router_quote だけです。まず subetha_router_list_routes を呼んでください。md-mpp-eth-snapshot がまだ一覧にあれば、その routeId と新しい UUID の requestId で subetha_router_quote を1回だけ呼んでください。なければ停止してください。受信側（エージェント→Router）と送信側（Router→プロバイダ）の protocol・network・asset・金額・decimals・有効期限・fundsMoveOnCredential を説明し、見積で必ず停止してください。署名、鍵の読取、ウォレット作成、承認、purchase はしないでください。他のツールも呼ばないでください。

または、ターミナルから一覧を取得

curl だけで送れるHTTPリクエストです。一覧のみを取得し、見積・署名・支払いは行いません。

curl -sS --max-time 30 https://router.subethalabs.com/mcp \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -H 'MCP-Protocol-Version: 2025-03-26' \
  --data '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"subetha_router_list_routes","arguments":{}}}'

JSON-RPC の result.structuredContent で、ok: true・routes・dynamic.profiles を確認してください。SSE形式では data: 行にJSONが入る場合があります。HTTP 200 だけでは成功とは判定できません。JSON-RPCやツールのエラーがないかも確認し、現在の件数は返された一覧を優先してください。

05 / 有料試用の前に

ローカル署名には、
明示的な承認を。

一般向けのローカル署名の導入手順は準備中です。有料試用には、利用可能なローカル署名手段、対応テストネットの資金（必要なネットワーク手数料を含む）、人間による明示的な承認が必要です。

支出が起こり得る署名工程より前に承認してください。 Tempo MPP は credential 作成時に送金し、purchase より先に資金が動きます。Solana MPP はローカルで署名のみを行い、購入時に Router が broadcast します。呼び出し側は手数料用の devnet SOL が必要です。fundsMoveOnCredential と各レールの挙動を確認してください。このフラグは支払い完了の証拠ではありません。

approval=quoteId は購入を見積に束縛しますが、人間の同意を証明しません。 クライアントが同意を得る必要があり、サーバは実際に人間が承認したかを検証できません。Router が拒否しても、未払いとは限りません。Tempo の credential 作成ですでに送金されている可能性があります。

paid_data_unavailable・unknown・awaiting_payment の後は自動再試行しないでください。 これらは未払いの証拠ではありません。まず既存の結果を照合してください。新しい購入には、新しい見積と、署名前の人間による再承認が必要です。返金の保証はありません。

上級者向け：条件に合う第三者プロバイダ

動的プロファイルで使えるURLには条件があり、任意のAPIが使えるわけではありません。公開 HTTPS、対応プロトコル・ネットワーク・資産、価格とチャレンジの制約に合う必要があり、リダイレクトは非対応です。見積にはプロバイダの代金と Router 手数料が含まれます。プロバイダは未検証です。対応する応答は GET による application/json のオブジェクトで、最大 256 KiB です。支払いが成立しても利用可能なデータが得られない場合があり、返金の保証はありません。

06 / FAQ

短い回答。

この手順で有料試用を完了できますか？+

この手順は一覧取得と固定ルートの見積で終了します。一般向けのローカル署名の導入手順は準備中です。MCPクライアントを接続するだけでは、署名手段やテストネット資金は用意されません。

Router は私の鍵を預かりますか？+

呼び出し側の秘密鍵を Router に渡すことはありません。呼び出し側がローカルで署名し、受信決済を許可し得る署名済みの支払い credential を渡します。Router は別個の送信決済に自身の鍵と事前資金を使います。

支払いは匿名になりますか？+

いいえ。資金が別であることは、支払い同士を関連付けられないことや匿名性を保証しません。このルーティング PoC は、秘匿性やアトミックな決済を保証しません。

本番運用できますか？+

いいえ。未監査・テストネット限定の概念実証です。過去の決済・データ取得記録は、現在の可用性や今後の購入結果を保証しません。
